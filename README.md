# RiseFit

اپلیکیشن اندروید فارسی و راست‌چین برای آلارم صبحگاهی، تمرین (باشگاه، شکم و خانه، فوتسال)، برنامه روزانه، هدف ۳۰/۶۰/۱۰۰ روزه و پیگیری پیشرفت.

> هر روز یک قدم به نسخه بهتر خودت نزدیک‌تر شو.

## وضعیت پروژه (صادقانه)

کد کامل نوشته و با بازبینی دستی کنترل شده (تعادل پرانتزها، import ها، منطق تقویم جلالی با تست جداگانه). ولی **این پروژه در محیط ساخت من کامپایل نشده**، چون SDK اندروید و دسترسی اینترنت به مخزن‌های Gradle آنجا نبود. پس اولین ساخت روی سیستم تو مرحله آزمایش واقعی است. اگر Android Studio خطای کامپایلی نشان داد، متن خطا را برای من بفرست تا درست کنم.

## ساخت و نصب

### روش ۱: Android Studio (ساده‌تر)
1. Android Studio نسخه Ladybug (2024.2) یا جدیدتر را نصب کن.
2. از منوی File ‏→ Open پوشه `RiseFit` را باز کن.
3. صبر کن Gradle Sync تمام شود (بار اول باید اینترنت داشته باشی تا وابستگی‌ها دانلود شوند و اگر SDK 35 نصب نیست، خودش پیشنهاد نصب می‌دهد).
4. گوشی را با USB وصل کن (گزینه Developer options ‏→ USB debugging روشن باشد) و دکمه Run را بزن.

### روش ۲: خط فرمان
```
./gradlew assembleDebug
```
فایل APK اینجا ساخته می‌شود: `app/build/outputs/apk/debug/app-debug.apk`
آن را به گوشی منتقل کن و نصب کن (اجازه «نصب از منبع ناشناس» لازم است).

نیازمندی‌ها: JDK 17 یا بالاتر، Android SDK 35، اندروید 8.0 (API 26) یا بالاتر روی گوشی.

## امکانات

- **خانه:** ساعت و تاریخ شمسی، آلارم بعدی و زمان باقی‌مانده، جمله انگیزشی هر روز، برنامه امروز با موارد انجام‌شده و باقی‌مانده، میانبرها، تصویر هدف.
- **آلارم:** چند آلارم، روزهای هفته، صدا، لرزش، مدت چرت، روشن/خاموش/ویرایش/حذف، صفحه آلارم روی قفل‌صفحه، بعد از خاموش کردن: جمله انگیزشی و اولین برنامه امروز. بعد از ریبوت دوباره تنظیم می‌شود.
- **برنامه روزانه من:** بیدار شدن، مدرسه، غذا، باشگاه، تمرین خانه، فوتسال، خواب؛ همه ساعت‌ها و روزها قابل ویرایش‌اند. روز بدون تمرین «روز استراحت» حساب می‌شود.
- **باشگاه:** برنامه هفتگی، ست/تکرار/وزنه/استراحت، راهنمای اجرا، عکس یا ویدئوی آموزشی برای هر حرکت، ثبت جلسه و سابقه.
- **شکم و کل بدن:** پلانک، کرانچ، بالا آوردن پا، شنا، اسکوات و غیره، تایمر حرکت و استراحت، علامت انجام‌شده، شدت سبک/متوسط/سنگین، هشدار ملایم برای ریکاوری.
- **فوتسال:** روز و ساعت، مدت، تمرین تکنیک/پاس/شوت/سرعت/آمادگی، یادداشت عملکرد.
- **هدف:** عکس یا تصویر انگیزشی، مرحله‌های روز ۳۰/۶۰/۱۰۰ با عکس واقعی (با تأیید خودت)، یادداشت و درصد پیشرفت، مقایسه خصوصی، حذف کامل.
- **تقویم:** هفتگی و ماهانه شمسی، نقطه رنگی برای باشگاه/خانه/فوتسال (توپر = انجام شده)، ثبت یا حذف جلسه برای هر روز.
- **پیشرفت:** سطح، امتیاز، استمرار سالم (یک روز استراحت زنجیره را نمی‌شکند)، نمودار ۸ هفته، نشان‌ها.
- **تنظیمات:** رنگ نئونی، یادآوری تمرین/آب/خواب، پشتیبان‌گیری و بازیابی (فایل JSON)، حذف عکس‌ها یا همه اطلاعات.

### بخش‌های نسخه ۱٫۱ (از صفحه خانه، «ابزارهای من»)
- **دفترچه برنامه روزانه:** برای هر روز کار با ساعت شروع و پایان، دسته (درس، مدرسه، بدنسازی، فوتسال، استراحت، شخصی)، تیک انجام‌شده و درصد پیشرفت همان روز. دکمه «انتقال کارهای انجام‌نشده به روز بعد» بدون سرزنش.
- **یادآورها و برنامه هفتگی:** یادآور دلخواه یک‌باره یا هفتگی با کلید روشن/خاموش برای هر کدام؛ فیلتر روزهای هفته.
- **عادت‌ها:** تیک روزانه، استمرار بدون عذاب وجدان (یک روز جا افتادن زنجیره را نمی‌شکند)، ۷ نقطه هفته‌ی اخیر که با لمس قابل اصلاح‌اند، آمار هفته و ماه شمسی.
- **هدف‌ها:** هدف ۳۰/۶۰/۱۰۰ روزه (یا تعداد دلخواه) با قدم‌های کوچک، درصد خودکار، نشان‌های ۲۵/۵۰/۷۵/۱۰۰٪، روز مانده، متوقف/ادامه/تکمیل.
- **تایمر تمرکز:** ۲۵ دقیقه (۵ استراحت) یا ۴۵ دقیقه (۱۰ استراحت)، شروع/توقف، ثبت خودکار جلسه، شمارنده جلسه‌ها و دقیقه‌های امروز و هفته. اعلان پایان جلسه حتی اگر برنامه بسته باشد.
- **دفترچه شخصی:** یادداشت با عنوان، متن، حالت (ایموجی)، جست‌وجو، ویرایش و حذف؛ قفل با PIN/الگو/اثر انگشت خود گوشی.
- **RiseAI:** دستیار فارسی. بدون اینترنت این‌ها را می‌فهمد: «برنامه امروز»، «درس ریاضی ساعت ۱۶ اضافه کن»، «یادم بنداز آب بخورم ساعت ۱۵»، «عادت‌ها»، «تمرکز»، «هدف‌ها»، «انگیزه». برای سؤال‌های آزاد باید سرور واسط خودت را وصل کنی (پایین را ببین).

## وصل کردن RiseAI به هوش مصنوعی واقعی (اختیاری)
کلید API هوش مصنوعی **هرگز داخل اپ یا APK نیست**، چون هر کسی می‌تواند APK را باز کند و کلید را بردارد. به‌جایش یک سرور کوچک واسط داری که کلید را نگه می‌دارد و اپ فقط با آن حرف می‌زند. نمونه آماده: `server/risefit-ai-worker.js` (Cloudflare Worker، پلن رایگان کافی است).

1. در Cloudflare یک Worker جدید بساز و محتوای فایل `server/risefit-ai-worker.js` را در آن بگذار.
2. در تنظیمات Worker بخش Variables and Secrets این‌ها را بساز: `ANTHROPIC_API_KEY` (کلید تو، از نوع Secret)، `APP_TOKEN` (یک رمز دلخواه، Secret). اختیاری: `MODEL`.
3. آدرس Worker (چیزی مثل `https://risefit-ai.نام-تو.workers.dev`) را در اپ بنویس: RiseAI ‏← آیکن چرخ‌دنده ‏← آدرس سرور، و همان `APP_TOKEN` را در «رمز دسترسی».
4. حتماً در کنسول Anthropic سقف هزینه ماهانه بگذار و اگر خواستی در Cloudflare یک قانون Rate limiting اضافه کن. هر کسی آدرس و رمز را داشته باشد می‌تواند از اعتبار تو مصرف کند، پس آن‌ها را به کسی نده.

فقط سؤال‌های آزاد در RiseAI به این سرور فرستاده می‌شوند. برنامه، عادت‌ها، هدف‌ها و دفترچه شخصی هیچ‌وقت فرستاده نمی‌شوند و دستورهای داخلی (مثل «برنامه امروز») اصلاً از گوشی بیرون نمی‌روند.

## حریم خصوصی
همه اطلاعات روی همان گوشی (Room و حافظه خصوصی برنامه) می‌ماند. حساب کاربری لازم نیست و همه بخش‌ها بدون اینترنت کار می‌کنند. تنها استثنا: اگر خودت در RiseAI آدرس سرور بگذاری، سؤال‌های آزادی که همان‌جا می‌نویسی به همان سرور می‌رود. عکس‌های هدف بدون هیچ تغییری کپی می‌شوند و فقط برای نمایش کوچک‌تر نشان داده می‌شوند.

## محدودیت‌های اندروید که باید بدانی
- **آلارم:** از `AlarmManager.setAlarmClock` استفاده شده که برای ساعت زنگ‌دار درست‌ترین راه است و به مجوز «آلارم دقیق» نیاز ندارد. روی گوشی‌های شیائومی، سامسونگ، هوآوی و ... باید RiseFit را از «بهینه‌سازی باتری» مستثنا کنی.
- **اعلان‌ها:** از اندروید ۱۳ به بعد مجوز اعلان لازم است؛ فقط وقتی آلارم یا یادآوری فعال می‌کنی پرسیده می‌شود. اگر ندهی، صدای آلارم پخش می‌شود ولی صفحه آلارم روی قفل‌صفحه ممکن است باز نشود.
- **نمایش روی قفل‌صفحه:** در اندروید ۱۴ به بعد ممکن است مجوز «نمایش تمام‌صفحه» دستی لازم باشد؛ در صفحه آلارم دکمه‌اش هست.
- **قفل دفترچه شخصی** جلوی باز شدن دفترچه داخل برنامه را می‌گیرد و از قفل خود گوشی استفاده می‌کند؛ رمزگذاری فایل نیست. فایل پشتیبان هم رمزگذاری نشده است، پس جای امن نگهش دار.
- **یادآورهای دلخواه و تایمر تمرکز** تا جای ممکن دقیق‌اند، ولی اگر گوشی‌ات برنامه را در پس‌زمینه محدود کند ممکن است دیر برسند؛ محدودیت باتری را بردار.
- **یادآوری‌های تمرین، آب و خواب** تقریبی هستند (ممکن است چند دقیقه دیر برسند) تا باتری کمتر مصرف شود. فقط آلارم صبحگاهی دقیق است.
- **پشتیبان‌گیری:** عکس‌های هدف داخل فایل پشتیبان هستند، ولی ویدئو/عکس آموزشی حرکت‌های باشگاه فقط به‌صورت پیوند ذخیره می‌شوند.
- **فونت:** از فونت فارسی پیش‌فرض سیستم استفاده شده. برای فونتی مثل وزیرمتن فایل `.ttf` را در `res/font` بگذار و در `Theme.kt` به Typography بده.
